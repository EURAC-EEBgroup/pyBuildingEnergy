# Weather data for ASHRAE Standard 140-2023

`USA_CO_Denver.Intl.AP.725650_TMY3.epw` is the local EPW representation used
by this example for the Denver weather data associated with station 725650
and the Section 7 test cases.

The building definition uses the site information specified by the standard
for the solar-geometry and altitude calculations. The EPW file supplies the
hourly outdoor temperature, humidity, irradiance and wind-speed series used
by the simulation.
