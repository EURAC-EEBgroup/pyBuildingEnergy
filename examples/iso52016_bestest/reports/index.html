clause 7.2.2.12
ISO 52016-1 clause 7.2 defines no pass/fail tolerance: the results and their deviations from the reference values are to be reported. The +/-10% flag is the tolerance used by tests/test_iso52016_bestest.py.
Reference values are not reproduced. They are ISO copyright and are printed in EN ISO 52016-1:2017, clause 7.2.4: Table 28 (heating needs), Table 29 (cooling needs), Table 30 (mean operative temperature), Table 31 (peak loads), Table 32 (free-floating extremes), Table 33 (hourly loads, January 4) and Table 34 (hourly operative temperature, January 4).
