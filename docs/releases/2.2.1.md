**pyBuildingEnergy 2.2.1** fixes hourly profiles in multizone simulations and adds ASHRAE 140 air-side verification cases.

`pip install --upgrade pybuildingenergy==2.2.1`

- Fixed missing imports in `ISO52016.simulate_envelope_multizone_free_floating`. With the default `use_profiles=True`, the error was previously caught silently, leaving all zones with constant internal-gain and ventilation profiles and falling back to the Italian holiday calendar. Zone-specific profiles and the appropriate country calendar are now used. Profile failures emit a `RuntimeWarning`. This fix can change multizone results; ASHRAE 140 case 960 is unchanged because it uses constant schedules.
- Added ASHRAE 140-2023 Section 11 air-side tests for ten fan-coil and single-zone cases using the EN 16798-5-1 AHU model. Coil loads are within 2% of the quasi-analytical solutions, with latent loads within 3.1%. The AE226 and AE245 cases impose the 100% outdoor-air condition reached by their economizer; economizer control is not modelled. Reference data are not distributed, so comparisons are skipped when they are unavailable.
- Checked the test suite on Python 3.12.9 and 3.13.2 with fresh dependencies. A test was adjusted for pandas 3 read-only arrays; library behaviour was unchanged by that adjustment.
