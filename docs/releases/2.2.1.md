**pyBuildingEnergy 2.2.1**: bug fix for hourly profiles in the multizone simulation.

`pip install --upgrade pybuildingenergy==2.2.1`

- Fix: `ISO52016.simulate_envelope_multizone_free_floating` did not import
  `HourlyProfileGenerator` and `get_country_code_from_latlon`. With `use_profiles=True` (the
  default) the per-zone profile generation failed silently and every zone used flat 1.0
  profiles: constant internal gains and ventilation factor, "IT" holiday calendar. Affects
  all earlier versions with the multizone simulation (2.1.7 and 2.2.0 included); multizone
  results with profiles change after upgrading. Single-zone simulations are not affected.
- A failure in the zone profile generation now emits a `RuntimeWarning` instead of passing
  silently.
- ASHRAE 140 case 960 (the multizone validation case) is unchanged: its schedules are
  constant.
- New ASHRAE 140-2023 Section 11 air-side tests (fan-coil AE100 and single-zone AE200
  series) for the EN 16798-5-1 AHU; reference results are not distributed.
- Checked on Python 3.12 and 3.13 (numpy 2.5, pandas 3.1).
