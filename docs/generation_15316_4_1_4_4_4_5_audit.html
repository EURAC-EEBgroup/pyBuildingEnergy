EN 15316-4-1 / 4-4 / 4-5 Generation Audit

This page documents the generator alternatives added next to the existing EN 15316-4-2 heat-pump path. The calculators use the same package contract as the other standards modules: timeseries, summary and inputs.

Implemented Modules

StandardClassBoundaryMain Outputs
EN 15316-4-1 CombustionBoilerSystemCalculator Heating/DHW boiler fuel input, part-load efficiency, return-temperature correction, standby losses and auxiliaries. EHW_gen_in_kWh, EHW_fuel_in_kWh, QHW_gen_loss_kWh, eta_HW_gen.
EN 15316-4-4 CogenerationSystemCalculator Thermal-led CHP, backup heat, useful electrical generation, self-consumption/export and auxiliaries. E_chp_fuel_in_kWh, E_chp_el_generated_kWh, E_chp_el_self_consumed_kWh, eta_chp_total.
EN 15316-4-5 DistrictEnergySystemCalculator District heating/DHW and optional cooling substation delivered energy, losses and auxiliaries. EHW_district_in_kWh, EC_district_in_kWh, QHW_gen_loss_kWh, SPF_HW_gen.

Run Commands

python examples/heat_pump_15316_4_2_example.py --scenario athens --calculation-path boiler-full --weather-source epw --path-weather-file examples/2020_Athens.epw
python examples/heat_pump_15316_4_2_example.py --scenario bolzano --calculation-path chp-full --weather-source epw --path-weather-file examples/2020_Milan.epw
python examples/heat_pump_15316_4_2_example.py --scenario bolzano --calculation-path district-full --weather-source epw --path-weather-file examples/2020_Milan.epw

Boundaries

These modules do not embed national annex defaults. Boiler efficiencies, CHP thermal/electrical efficiencies, district substation efficiencies and loss factors should be supplied from project, manufacturer or approved national-annex data for formal studies.
