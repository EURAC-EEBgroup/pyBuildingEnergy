## 2. Modalità di `HeatingSystemCalculator`

### Distribuzione

`distribution_calculation_mode = simplified`

- usa il calcolo aggregato storico presente in `iso_15316_1.py`

`distribution_calculation_mode = analytical`

- usa `DistributionSystemCalculator` di `distribution_15316_3.py`
- richiede `distribution_15316_3_config`

### Generazione

`generation_calculation_mode = legacy`

- mantiene il comportamento storico del modulo `iso_15316_1.py`

`generation_calculation_mode = boiler_15316_4_1`

- usa `BoilerGeneratorCalculator` di `generation_15316_4_1.py`
- richiede `boiler_generation_config`

## 3. Flusso operativo

1. `EmissionSystemCalculator` produce `Q_H_em_in_kWh` e `W_H_em_aux_kWh`
2. `HeatingSystemCalculator` riceve questi valori e calcola i parametri operativi
3. Se richiesto, la distribuzione passa nel ramo analitico EN 15316-3
4. La generazione può restare legacy oppure passare al modulo EN 15316-4-1

## 4. Esempio

```python
from pybuildingenergy import HeatingSystemCalculator

calc = HeatingSystemCalculator(
    {
        "distribution_calculation_mode": "analytical",
        "distribution_15316_3_config": {...},
        "generation_calculation_mode": "boiler_15316_4_1",
        "boiler_generation_config": {...},
    }
)
```

## 6. Nota operativa

La catena completa è pensata per evitare doppi conteggi:

- l'emissione va corretta una sola volta
- la distribuzione deve alimentare la generazione con il proprio `Q_H_dis_in`
- la generazione deve usare tabelle esplicite per i casi di generatore
