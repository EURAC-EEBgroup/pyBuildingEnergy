EN 15316-4-3 / 4-6 Renewables Audit

The renewable branch is implemented by RenewableEnergySystemCalculator. It can be run before heating generation to reduce heating/DHW loads with solar thermal useful heat and after or alongside generation to account for PV self-consumption/export.

Calculation Boundary

Sub-systemInput DataImplemented Output
Solar thermal Collector area, annual useful yield, loop efficiency, priority dhw_first, heating_first or proportional. Q_H_after_solar_kWh, Q_W_after_solar_kWh, solar heat used and unused.
Photovoltaics Capacity, annual yield, performance ratio and self-consumption fraction. If irradiance is present, it is used for timing; otherwise a deterministic daylight/month profile is used. E_PV_gen_kWh, E_PV_self_consumed_kWh, E_PV_export_kWh, E_grid_after_PV_kWh.

Run Commands

python examples/heat_pump_15316_4_2_example.py --scenario athens --calculation-path full-renewables --weather-source epw --path-weather-file examples/2020_Athens.epw
python examples/heat_pump_15316_4_2_example.py --scenario bolzano --calculation-path full-renewables --weather-source epw --path-weather-file examples/2020_Milan.epw

Boundaries

The implementation is a simulation-ready accounting layer. Detailed collector heat balance, inverter clipping, battery storage, shading and formal national annex defaults are not embedded; use measured or project-specific yield inputs where required.
