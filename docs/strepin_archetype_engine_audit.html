Italian STREPIN Archetype Engine Audit

The STREPIN workbook is treated as input data. The runner builds pyBuildingEnergy BUI objects for each archetype/package, runs ISO 52016 and then applies the European generator standards to calculate pre- and post-retrofit performance.

Default EN-Standards Chain

STREPIN workbook archetype/package
  -> BUI envelope and system metadata
  -> ISO 52016 space heating/cooling demands
  -> EN 15316-4-1 boiler generation for gas packages
     or EN 15316-4-2 heat-pump generation for electric heat-pump packages
  -> EN 16798-13 cooling generation
  -> EN 15316-4-6 PV generation/self-consumption
  -> final and non-renewable primary energy summary

Boundaries

The current STREPIN chain uses European generator standards and the workbook measure metadata. It does not yet add full emission, distribution, DHW design sizing and storage standards to every archetype case; those detailed standards are available in the Athens/Bolzano workflow and can be threaded into STREPIN archetype batches once archetype-specific system lengths, storage data and emitter data are available.
