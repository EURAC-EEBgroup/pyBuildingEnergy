Italian STREPIN Archetype Engine Audit

The STREPIN workbook is treated as input data. The runner builds pyBuildingEnergy BUI objects for each archetype/package, runs ISO 52016 and then applies the European EPB standards to calculate pre- and post-retrofit performance. Workbook package levels remain available, and arbitrary combinations can be built from the same measure levels.

Default EN-Standards Chain

STREPIN workbook archetype/package
  -> BUI envelope and system metadata
  -> ISO 52016 space heating/cooling demands
  -> EN 15316-4-1 boiler generation for gas packages
     or EN 15316-4-2 heat-pump generation for electric heat-pump packages
     or EN 15316-4 biomass, EN 15316-4-4 CHP, EN 15316-4-5 district heat overlays
  -> EN 16798-13 cooling generation
  -> EN 15316-4-3/4-6 solar thermal, PV and optional battery dispatch
  -> EN 15193-1 lighting and EN 16798-5/7 ventilation when requested
  -> EN 15232-1 / EN ISO 52120-1 BACS service factors when requested
  -> EN ISO 52000-1 delivered/exported primary-energy accounting
  -> EN 15459-1 global cost summary

Combination Inputs

InputMeaning
--packages P00,P09Uses complete package definitions from the workbook. P00 is baseline/pre-retrofit.
--measure-levels wall=2,roof_floor=2,windows=2,heating=3,pv=2Builds a custom case from workbook measure levels; omitted workbook measures default to level 1.
--extra-measuresAdds engine-side measures not present as workbook package levels: lighting-controls, ventilation-hrv, bacs-a/bacs-b, solar-thermal, battery-5, biomass-boiler, district-heat, chp, pv-shading-10.
--extra-measure-jsonSupplies explicit parameter values for those overlays, for example solar-thermal area, battery capacity or BACS class.
--export-credit-methodnone keeps the headline primary-energy indicator comparable to STREPIN grid-delivered accounting; symmetric credits exported electricity in the EN ISO 52000-1 net balance.

Boundaries

The workbook provides explicit package levels for opaque envelope, windows, heating generator and PV. Lighting, heat-recovery ventilation, BACS, solar thermal, batteries, biomass, CHP, district heat and PV shading are currently engine-side overlays with default costs and efficiencies. They can be simulated now, but project/national-plan values should replace the defaults when available. Full archetype-specific EN 15316-2/3/5 detail still needs emitter types, distribution lengths, storage sizes and control data for each STREPIN archetype.
